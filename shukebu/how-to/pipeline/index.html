洽談中與歷程教學：願望、報價、成交一條線，不再重複記

約 3 分鐘學會・更新：2026-11-18

情境：林姐八月說想要一條珍珠項鍊，你記在願望清單；十一月報了價；這週成交了。以前這件事散在願望清單、報價紀錄、購買紀錄三個地方，看起來像三筆資料。

現在它從頭到尾就是一張卡：待購 → 報價中 → 成交後移進購買紀錄，而「歷程」時間軸隨時能回看整段來龍去脈。

操作步驟

  1. 記下客人想要的

    在客戶檔案的 洽談中 點 新增，選 新增願望。品項可以直接從商品目錄選；順手寫下 猶豫原因 與 目標場合，之後跟進更有話聊。

  2. 轉成報價

    客人問到價錢，打開那張願望卡點 建立報價：品項自動帶入，有對應商品時連價格、分類都幫你填好。設定 有效期限 可以開啟到期前自動提醒。卡片狀態變成 報價中。

  3. 跟進

    到期前提醒跳出來，點開提醒就能直接看這筆報價；洽談中的卡片上也看得到金額與效期。

  4. 成交

    報價詳情點 標記成交 · 帶入記錄成交，儲存後這張卡離開洽談中，只留在 購買紀錄——一件事永遠只出現在一個地方。

  5. 回顧歷程

    在願望、報價或購買詳情都有 歷程 時間軸：加入願望清單 → 報價 → 成交，每一步都能點回當時的紀錄。

小技巧

  • 直接成交不用先走願望或報價——洽談中只管還在進行的事。
  • 標記未成交的報價會淡化留在洽談中並顯示原因，之後可以從願望再建立新報價。
  • 刪除報價時，來源的願望會自動恢復「待購」。

常見問題

直接成交可以嗎？一定要先建願望或報價？
完全可以直接記錄成交。洽談中只管「還在進行的事」，從哪一步開始都行。
已購買的願望去哪了？
成交後那張卡離開洽談中，只留在購買紀錄；資料都在，從購買詳情的歷程時間軸可以點回去看當初的願望與報價。
報價沒成交會怎樣？
標記未成交後卡片會淡化留在洽談中並顯示原因；想再試一次，可以從願望再建立一筆新報價。
更新後舊的願望和報價會亂掉嗎？
不會。原本的資料自動歸位：待購與報價中的進洽談中（同一件事併成一張卡），已購買的只留在購買紀錄。
