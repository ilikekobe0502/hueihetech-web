功能介紹 免費試用 14 天

連接 LINE 官方帳號

客人的 LINE 訊息，自動進熟客簿。五個步驟，大約 5 分鐘。

連接後可以做什麼

即時通知客人加好友、傳訊息，手機馬上跳通知
自動對應客人配對一次，之後的訊息都歸到同一份客戶檔案
AI 找重點訊息裡提到的喜好、預算、想要的東西，整理好讓你一鍵存入
直接用 LINE 回AI 擬好的生日祝福、到貨通知，從熟客簿直接傳給客人

開始前，你需要

  • 一個 LINE 官方帳號（免費的輕用量方案也可以），而且你是管理員
  • 手機上已安裝熟客簿 App，並登入你的帳號
  • 一台電腦：LINE 的後台在電腦上操作比較方便

只能連接 LINE 官方帳號。你個人 LINE 的好友和聊天，熟客簿讀不到。

五個步驟

1

在官方帳號後台啟用 Messaging API

  1. 到 LINE Official Account Manager，選你的官方帳號
  2. 點右上角 設定，再點左側 Messaging API
  3. 按 啟用 Messaging API，選擇或建立一個「服務提供者（Provider）」，依畫面同意條款
服務提供者選定後就不能更改。用公司或品牌名稱建立即可。
2

複製 Channel ID 和 Channel secret

啟用後，同一頁就會出現 Channel ID 和 Channel secret，兩個都複製下來。

之後要再找，也可以到 LINE Developers Console → 你的 Provider → 你的 channel → Basic settings。

3

發行長期的 Channel access token

  1. 到 LINE Developers Console，用同一個 LINE 帳號登入
  2. 點你的 Provider → 你的 channel → 上方 Messaging API 分頁
  3. 捲到最下面的 Channel access token (long-lived)，按 Issue，複製產生的那一長串
4

在熟客簿貼上，按「驗證並連接」

打開熟客簿 → 設定 → LINE → LINE 官方帳號，把三組資料貼上，按 驗證並連接。

熟客簿會檢查資料是否正確，並自動幫你設好 Webhook 網址，不用自己填。

5

打開「Use webhook」（最常漏掉的一步）

  1. 回到 LINE Developers Console → 你的 channel → Messaging API 分頁
  2. 在 Webhook settings 找到 Use webhook，把開關打開
  3. 回到熟客簿，按 開好了，重新檢查
這個開關沒開，Webhook 網址設好了，LINE 也不會把客人的訊息送過來。熟客簿顯示「還收不到客人訊息」，就是這一步還沒做。

完成！之後客人加你好友或傳訊息，就會出現在熟客簿的「待配對」清單。配對到客戶檔案一次，之後的訊息都會自動歸過去。

常見問題

圖文選單、歡迎訊息、自動回應還會照常運作嗎？

會。這些都在官方帳號後台設定，連接熟客簿不會改動它們。

我原本有接聊天機器人或其他 CRM，會受影響嗎？

會。一個官方帳號只能設一個 Webhook 網址，連接後會改成熟客簿的網址，原本的服務就收不到客人訊息了。若你還需要原本的服務，請先確認再連接。

從熟客簿傳訊息給客人要錢嗎？

熟客簿不另外收費，但主動傳出的訊息會用到你官方帳號方案的每月訊息則數。熟客簿裡會顯示本月剩下的額度，方案與則數依 LINE 官方帳號的規定。

客人的資料安全嗎？

Channel secret 和 access token 都加密保存。客人訊息的原文依你設定的天數（30 到 365 天）自動刪除；AI 整理出的重點存入客戶檔案後會一直保留。

之前就加好友的客人，也會出現嗎？

已認證或 Premium 的官方帳號，可以在熟客簿按「匯入好友」一次帶進來；一般帳號則是在客人下一次傳訊息時自動出現。

想取消連接怎麼做？

在熟客簿的 LINE 官方帳號頁按「中斷連接」。中斷後不會再收到客人訊息，已配對的紀錄也會一併移除。若之後要改接其他服務，記得到 LINE Developers Console 把 Webhook 網址換掉。
